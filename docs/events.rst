==========
Row events
==========

Row events are generated by MySQL when data in a table is modified.

The main row event types are:

* ``WriteRowsEvent`` - generated when rows are inserted.
* ``UpdateRowsEvent`` - generated when rows are updated.
* ``DeleteRowsEvent`` - generated when rows are deleted.

Common row event attributes
---------------------------

``schema``
    The name of the database schema containing the table.

``table``
    The name of the table that was modified.

``primary_key``
    Primary key information associated with the table.

``columns``
    Column metadata associated with the table.

``rows``
    The rows affected by the event.

WriteRowsEvent
--------------

``WriteRowsEvent`` represents an INSERT operation.

For each row in ``event.rows``, the inserted values are available through
the ``values`` key.

Example::

    from pymysqlreplication.row_event import WriteRowsEvent

    for event in stream:
        if isinstance(event, WriteRowsEvent):
            for row in event.rows:
                print(row["values"])

UpdateRowsEvent
---------------

``UpdateRowsEvent`` represents an UPDATE operation.

For each row in ``event.rows``, the values before and after the update
are available through ``before_values`` and ``after_values``.

Example::

    from pymysqlreplication.row_event import UpdateRowsEvent

    for event in stream:
        if isinstance(event, UpdateRowsEvent):
            for row in event.rows:
                print("Before:", row["before_values"])
                print("After:", row["after_values"])

DeleteRowsEvent
---------------

``DeleteRowsEvent`` represents a DELETE operation.

For each row in ``event.rows``, the deleted values are available through
the ``values`` key.

Example::

    from pymysqlreplication.row_event import DeleteRowsEvent

    for event in stream:
        if isinstance(event, DeleteRowsEvent):
            for row in event.rows:
                print(row["values"])
